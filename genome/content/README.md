# Forma content

## Voice

Clear. Calm. Precise.

Help the user understand the next decision. Explain consequences directly and avoid alarmist or promotional phrasing. Precision should clarify what is known; it should not imply certainty about an outcome the product cannot guarantee.

## Action labels

Prefer explicit, verb-led actions that communicate what will happen.

Prefer:

- Delete workspace
- Create project

Avoid generic labels when a more explicit action is available:

- Confirm
- Submit

Review labels in their actual context. These examples support judgment rather than a universal word blacklist. The [explicit-action-label rule](../rules/README.md#explicit-action-labels) establishes the recommendation; its level and validation classification live in [rule metadata](../rules/rules.ts).
